1 Physical Instrumentation & Wiring

  • Supply Air Probe DS18B20 #1 (5–8 cm in free airflow, P27 / GPIO27)
  • Return Air Probe DS18B20 #2 (Intake grille, shared P27 / GPIO27 bus)
  • Room Temp & RH DHT11 3-Pin Module (P26 / GPIO26, 3V3)
  • Sensor Placement DHT11 mid-room (~1.5m high, away from cold draft)
  • Electrical Safety 100% low-voltage USB-powered (ESP32 NodeMCU 38-Pin). No mains wiring.
Bus: OneWire(P27, 1× 4.7kΩ pull-up) + Digital(P26)
Firmware: 115200 baud, ~5s spacing (climatwin_esp32.ino)

2 Data Contract & Ingestion

  • Microcontroller Output ms, probe0_C, probe1_C, room_C, room_RH
  • Python Logger logger/log_serial.py (per-row flush)
  • Sanitization Offset calibration + monotonic reboot guard
  • Outdoor Source Open-Meteo REST API (10-min cache / typed fallback)
  • Storage Schema 8-col CSV (ts_iso, ms, supply, return...)
Sidecar Metadata: *.meta.json (setpoint, fan, offsets)
Phases: clean1 (baseline) ➔ blocked (filter fault) ➔ clean2

3 Digital Twin Core (twin/)

  • Onset Detection Piecewise linear regression (slope < -0.06)
  • Noise Filter 3-sample rolling median window
  • Mathematical Fit First-order Newton pull-down via SciPy curve_fit
  • Health Ratio min(100, 100 * τ_baseline / τ_now)
  • Alert Rule Health < 80 for 3 consecutive 60s fits
Model: T_room(t) = T_final + (T_0 - T_final) · exp(-t / τ)
Fit Window: First 15 minutes of detected cooling (R² ≥ 0.90)

4 Verification & User Interface

  • Dashboard UI Streamlit (app/dashboard.py)
  • Visualization 4 Telemetry lines + Digital Twin Curve Overlay
  • Demo Acceleration 10× Replay engine with timeline scrubbing
  • Push Alert Telegram bot notification on sustained degradation
  • Proof of Service 2-Page PDF (FPDF2): Normalized Δτ% & ₹ impact
Weather Normalization: τ_expected = m · T_outdoor + c
Energy Savings (est): minutes_saved / 60 × kW_nameplate × ₹/kWh
Honest Scientific Disclosure: System tracks sensible cooling pull-down dynamics. No direct electrical mains power is measured. Energy and rupee figures are estimates (runtime × nameplate kW × tariff), not physical power meter readings.
