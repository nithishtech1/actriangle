3. REFERENCE FIRMWARE CONTRACT (ESP32 + 2x DS18B20 + DHT11)
================================================================================
Already printing cleanly? Keep your working library/pins! Only confirm
Serial outputs 5 comma-separated numbers matching this format at 115200 baud:

#include <OneWire.h>             // Works on ESP32 Core v2.0.17 (or OneWireNg on Core 3.x)
#include <DallasTemperature.h>
#include <DHT.h>

#define ONE_WIRE_BUS 27          // BOTH DS18B20 Yellow wires + 4.7k pull-up to 3V3 (Col 24)
#define DHTPIN 26                // DHT11 Signal (out/S) -> P26
#define DHTTYPE DHT11

OneWire ow(ONE_WIRE_BUS);
DallasTemperature ds(&ow);
DHT dht(DHTPIN, DHTTYPE);

void setup() {
  Serial.begin(115200);
  delay(1000);
  ds.begin();
  dht.begin();
  Serial.print("# DS18B20 count: ");
  Serial.println(ds.getDeviceCount());
  Serial.println("ms,probe0_C,probe1_C,room_C,room_RH");
}

void loop() {
  ds.requestTemperatures();
  float p0 = ds.getTempCByIndex(0);
  float p1 = ds.getTempCByIndex(1);
  float roomC = dht.readTemperature();
  float roomRH = dht.readHumidity();

  Serial.printf("%lu,%.2f,%.2f,%.2f,%.1f\n", millis(), p0, p1, roomC, roomRH);
  delay(5000);
}

Live Capture Watch-Outs (No Fake Data):
- NEVER replace missing/stuck values (-127, 85, nan) with random numbers.
- If a probe drops mid-run, push male jumper pins firmly into Col 24 (P27)
  and keep the single 4.7 kOhm pull-up tight to 3V3 (two in parallel is
  optional only if long extension cables drop signal).
- If only 1 probe works or DHT11 outputs nan/coarse steps, send Nithish a
  wiring photo + 5 Serial lines immediately.

4. TONIGHT'S FAST, RELIABLE 3-PHASE AC TEST PROTOCOL
================================================================================
1. Pick a Small, Enclosed Room:
   Close all doors, windows, and curtains. Keep AC setpoint identical (e.g.
   18 C) and fan speed fixed across all 3 runs. Take a photo of AC nameplate kW
   for the report.

2. Mount Sensors Safely:
   - Supply Probe: tape 5-8 cm in discharge airflow (do not touch plastic louvers).
   - Return Probe: tape at top intake grille.
   - DHT11: mid-room (~1.5 m high, away from direct cold draft and ESP32 heat).

3. CRITICAL NIGHT-TIME RULE (Avoid Rejected Curves!):
   Because it is night, the room cools quickly. BEFORE starting EACH phase,
   turn AC OFF, open the door, and run the ceiling fan for ~20 minutes so the
   room warms back up to 28-30 C. twin/fit_tau.py rejects runs that drop less
   than 0.5 C or plateau early!

4. Run & Log All 3 Phases (20-25 min each):
   Close Arduino Serial Monitor first, then run from repo root:

   python -m logger.log_serial --port COMx --phase clean1 --setpoint-c 18 --duration-min 22
   # Warm room back up (~20 min, door open + fan ON), power AC OFF, half-cover filter with cardboard & photo
   python -m logger.log_serial --port COMx --phase blocked --setpoint-c 18 --duration-min 22
   # Remove cardboard, warm room back up (~20 min)
   python -m logger.log_serial --port COMx --phase clean2 --setpoint-c 18 --duration-min 22

5. Record 45s Demo Video Clip:
   Film mounting the probes, clean run, sliding cardboard over the filter,
   and removing it.

6. Validate & Push to GitHub:
   Run:
     python tools/check_csv.py data/raw
     python -m twin.fit_tau data/raw
   Then commit/push CSVs and ambient offsets to GitHub.
